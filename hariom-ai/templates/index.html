API Key setup karna padega

Aapne abhi tak AI API key set nahi ki hai. Asli AI jawab dene ke liye ye zaruri hai.

  1. Google Gemini API key lein — yahan free key banayein.
  2. Project folder mein .env.example file ko copy karke uska naam .env rakhein.
  3. .env file mein GEMINI_API_KEY= ke baad apni key paste karein.
  4. Server ko dobara chalu karein (batch file wapas chalayein).
